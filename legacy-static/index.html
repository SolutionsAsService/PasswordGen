How it works

Unbiased selection

Characters are drawn with rejection sampling over crypto.getRandomValues, so no character is favoured by modulo bias. Shuffles use the same method.

Honest entropy

The bits shown are computed from the actual pool size and length, not guessed from a rule of thumb. Passphrase entropy uses the exact word-list size.

Nothing leaves the page

Generation runs entirely in this document. There is no network request and no analytics; the only thing saved is your theme choice.

Crack-time estimate

Shown as an order of magnitude at an assumed 1010 guesses/second offline. Real time depends on the site's hashing, which this page cannot know.
